连接 Supabase 并完成服务端配置后，登录客户可以提交待处理订单。在线支付与服务器自动开通尚未启用，创建订单不会扣款。

页面展示的价格和配置是真实价格吗？

当前价格与规格为演示参考。正式上线后将以后台商品目录、实际供应商报价和可售库存为准。

可以选择哪些数据中心？

首页展示的是规划区域。具体套餐可用机房需要由运营后台配置，并以实时可售状态为准。

配置预览提供 Ubuntu、Debian、AlmaLinux 与 Windows Server 等示例选项，最终可选系统取决于产品和供应商支持情况。

如何管理账户和订单？

可以进入账户中心注册或登录。订单列表需要在真实订单流程接通后才会显示实际订单。
